Emberkeep — Last Lantern of the Hollow: a top-down arena-survivor roguelite. You carry the last lantern through waves of hollow creatures in the dark, kiting, dodging, and picking up upgrades between waves to survive the night. Plain HTML/JS, no libraries, no network — just a browser. Play-tested to a win and a loss with zero console errors.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
